# libSceAgcDriver

## add Functional

- [Context registers through SET_CONFIG_REG on a PS4](../../../core/libs/prx/libSceAgcDriver/Execution/src/Pm4.cpp) (libSceAgcDriver, PS4) - with GCN guest shaders, a SET_CONFIG_REG whose offset is 0x8000-0x83ff writes context registers 0-0x3ff. The config bank starts at 0x2000, so Red Dead Redemption 2's offset 0x8102 is VGT_INDX_OFFSET (0xa102). Other config offsets are still refused. Not measured on a console.
- [1_5_5_5 targets with the alternate component order](../../../core/libs/prx/libSceAgcDriver/Graphics/src/State.cpp) (libSceAgcDriver) - COLOR_1_5_5_5 UNORM with COMP_SWAP ALT renders through A1R5G5B5 without exchanging X and Z, the layout of B5G5R5A1 in Mesa's `si_translate_colorswap`. Not measured on a console.
- [GCN vertex instance step rates](../../../core/libs/prx/libSceAgcDriver/Execution/src/Driver/Draw/DrawCapture.cpp) (libSceAgcDriver, PS4) - a legacy GCN vertex program's v1 and v2 hold the instance index divided by VGT_INSTANCE_STEP_RATE_0 and _1 (context 0x2a8 and 0x2a9) when SPI_SHADER_PGM_RSRC1_VS.VGPR_COMP_CNT requests them. The rates are part of the shader cache key. A rate of 0, the CLEAR_STATE value, divides by 1, and the console result for it is not known. The rates are not in serialized recompile requests, so a replayed request uses 1.

- [PS4 Pro occlusion queries](../../../core/libs/prx/libSceAgcDriver/Execution/src/Pm4.cpp) (libSceAgcDriver, PS4) - a GCN title whose param.sfo has the Neo mode attribute dumps sixteen DB counter pairs per query, 16 bytes apart, as Red Dead Redemption 2 enables with PIXEL_PIPE_STAT_CONTROL instance mask 0xffff and reads 0x100 bytes per query; other GCN titles dump eight. The count follows the PS4 Pro's 64 render back ends against the PS4's 32. Not measured on a console.

## change [Single-sample dithered alpha-to-coverage]

- [Single-sample dithered alpha-to-coverage](../../../core/libs/prx/libSceAgcDriver/Graphics/src/State.cpp) (AGC driver) - a single-sample target with `DB_ALPHA_TO_MASK` 0x18701 (no `PA_SC_AA_CONFIG` or `DB_EQAA` samples) covers its one sample when alpha plus the pixel's offset reaches one: the measured eight- and two-sample tables both follow covered samples = floor(alpha * samples + (2 * ALPHA_TO_MASK_OFFSETn + 1) / 8), n = x + 2y in the quad, and 0x18701's offsets 3, 1, 0, 2 put the thresholds at 1/8, 5/8, 7/8 and 3/8. Red Dead Redemption 2 (CUSA08519) draws this way while loading. The single-sample table is that formula, not a console measurement; an initial Vulkan `alphaToCoverageEnable` readback on RADV (RX 6650 XT) for a 4x4 target showed quad-granular coverage, which is the driver's own dither and not `DB_ALPHA_TO_MASK`. Single-sample 0xe701 still throws `requires two matched raster/DB_EQAA samples and one pixel iteration`; Bugsnax (PPSA01503) reaches it at the Flavor Falls bridge cutscene transition. Closes when: the single-sample pattern is measured on PS4 or PS5 hardware

## change [PS4 (GCN) thick and layered surfaces]

- [PS4 (GCN) thick and layered surfaces](../../../core/libs/prx/libSceAgcDriver/Graphics/src/TextureTiling.cpp) (libSceAgcDriver, PS4) - a 3D texture in tile mode 19 (`Thick_1dThick`) uses addrlib's 8x8x4 `ADDR_THICK` micro tiles, depth padded to 4, each level as slabs of four slices; nonzero levels below four slices degrade to 1D thin with one slice per stride and pitch raised until the slice is 256-byte aligned (addrlib `ComputeSurfaceInfoMicroTiled` and SI `HwlGetSizeAdjustmentMicroTiled`); a block-compressed volume, a thick mode on a non-3D T# and a storage image of a volume with mips throw. Modes 15 and 20 to 26 throw, and so does a depth plane of a layered surface with several mip levels. A storage image of such a surface is tracked as one unit or as 64 KiB blocks, never per layer, because its layers are not contiguous; Red Dead Redemption 2 (CUSA08519) writes one from a compute shader. A sampled layered surface with several mip levels is stored level by level, and a 3D surface in a thin mode the same way, its level n holding max(1, depth >> n) slices, rounded up to a power of two with `POW2_PAD` as its width and height are, following [ac_surface](https://gitlab.freedesktop.org/mesa/mesa/-/blob/mesa-24.0.0/src/amd/common/ac_surface.c#L776) and addrlib's [PostComputeMipLevel](https://gitlab.freedesktop.org/mesa/mesa/-/blob/mesa-24.0.0/src/amd/addrlib/src/core/addrlib1.cpp#L3818-L3842). Neither is checked on a console; [GcnDetile.cpp](../../../core/libs/prx/libSceAgcDriver/tests/execution/GcnDetile.cpp) covers the thin and depth modes; mode 19 has layout tests only.

# libSceGnmDriver

## add Functional

- [sceGnmMapComputeQueueWithPriority](../../../core/libs/prx/libSceGnmDriver/Export.cpp) (libSceGnmDriver, PS4) - maps the queue as sceGnmMapComputeQueue does and ignores the priority, because the host has no compute queue priorities.
- [PS4 Gnm shader update and compute writers](../../../core/libs/prx/libSceGnmDriver/Export.cpp) (libSceGnmDriver, PS4) - sceGnmUpdateVsShader, UpdateGsShader, UpdateHsShader and UpdatePsShader350 write the same register packets as the Set forms. They do not use NOP-wrapped context writes, because the AGC driver applies only real register packets. UpdateHsShader pads with a NOP up to the size the caller reserved. sceGnmSetPsShader350, SetCsShaderWithModifier, DispatchDirect, DispatchIndirect, DispatchIndirectOnMec, ComputeWaitOnAddress and ComputeWaitSemaphore follow the packets of libSceGnmDriverForNeoMode. sceGnmGetPhysicalCounterFromVirtualized fails, and sceGnmLogicalTcaUnitToPhysical is not implemented. Not measured on a console.
- [PS4 draw command buffer chains](../../../core/libs/prx/libSceGnmDriver/Export.cpp) (libSceGnmDriver, PS4) - an INDIRECT_BUFFER in a draw command buffer is followed at submission. A call runs its buffer and returns, at most two levels deep. A chain continues in its buffer and skips the rest of the current one. A released REWIND is dropped. An unreleased REWIND ends the submission: a detached thread waits for its valid bit every 0.1 ms, then lowers and submits the words after it. Later submissions and sceGnmSubmitDone wait behind it in order. An unreleased REWIND inside a called buffer, and predicated INDIRECT_BUFFER packets, are not implemented. VideoOut flips that the title submits directly do not wait behind a stalled REWIND.
